# About

This is my second project related to a hackpad this summer and I have faced severely less difficulties than my first time. I am glad that I was able to retain most of the skills I learned previously and use them again. My build consists of an encoder, some keys, and a case.

# Features:
a 2-part case (3D printed)
EC11 Rotary encoder
3 keys/switches
4 M2 heatset inserts and screws

This case has 2 separate parts: one for the bottom of the case and one for the top. The top part consists of the cutouts for my switches and encoder, and the other half is the bottom of my case. I am planning on assembling the case together using M2-Heatset inserts and screws on each corner. It also has 4 small raised pillars in the bottom of the case for my pcb to rest on. Additionally, I made a cutout for the USB on the case.

# BOM
This is everything that should be needed to make this hackpad: 

* 3x Cherry MX-style Switches
* 3x White Blank DSA Keycaps
* 4x M3x5x4mm Heatset inserts
* 4x M3x16mm Screws
* 1x EC11 Rotary Encoder
* 1x XIAO RP2040
* 1x Case (2 printed parts)
